Your personal swarm of agents.

You're the queen bee. Your orchestrator rallies a hive of Claude Code and Codex workers on your Mac, and no honey leaves the hive until you've had a taste.

Download for macOS Read the docs

Apple silicon · macOS 13 or later

Plan it. The swarm builds it. You review and ship.

  1. Tell the orchestrator

    Describe what you want to build. It splits the work into tasks and gives each one its own branch, worktree and tab.

  2. Watch the swarm

    Each task gets an orchestrator. It spawns Claude Code and Codex workers, answers their questions and starts dev servers and tests.

  3. Review, then ship

    Comment on code while agents work. Approve the combined diff, run your checks and open the PR.

Built like a terminal.

Real terminals

Agents run in GPU-rendered terminals built on libghostty. Nothing is wrapped or hidden.

Agents keep running

Quit the app and your agents keep working. Reopen it and the screen is exactly where you left it.

Worktree per task

Every task gets its own branch and worktree, with your setup script, copied env files and its own ports.

Live review

See every change as it happens, grouped by the agent that wrote it. Your comments go straight back to that agent.

Your terminal is yours

Open a terminal no agent can read, type into, resize or close.

Usage in the menu bar

See your Claude and Codex limits at a glance, and stop every agent from the menu bar.

Notifications that matter

Swarm pings you when an orchestrator needs a decision or a task is ready for review. Nothing else.

Accessible by default

Every control has a VoiceOver label, everything works from the keyboard, and both themes meet WCAG AA contrast.

Agents can control Swarm

Every agent gets the swarm CLI and MCP tools. Spawn workers, start a dev server in its own terminal, wait for tests, stop what is done. Your own terminal stays off-limits.

Your CLAUDE.md, AGENTS.md, skills and hooks keep working.
