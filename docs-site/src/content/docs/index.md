Swarm is a macOS app that runs a group of coding agents on one task. One agent, the orchestrator, splits the task and starts the workers. The workers do the parts. You review the combined diff and open the pull request.

Each agent is a Claude Code or Codex process in a real terminal. A background process, the daemon, owns those terminals. Agents keep running when you quit the app.
