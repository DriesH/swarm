---
title: Keyboard shortcuts
description: Every keyboard shortcut in Swarm, grouped by where you use it.
---

Every action in Swarm works from the keyboard. This page lists the shortcuts. **Settings › Keyboard** lists only some of them: six groups (Workspace, Terminals, Swarm view, Review, File tree and Settings).

You cannot change shortcuts. That page is read-only.

Keys follow the macOS order: ⌃ Control, ⌥ Option, ⇧ Shift, ⌘ Command.

## Window and views

| Keys | Action |
|---|---|
| ⌘K | Open the command palette |
| ⇧⌘R | Open Review |
| ⌘B | Show or hide the sidebar |
| ⌘, | Open Settings |
| ⌃⌘F | Enter or exit full screen |
| ⌘M | Minimize the window |
| ⌘H | Hide Swarm |
| ⌥⌘H | Hide other apps |
| ⌘Q | Quit |
| ⇧F10 | Open the context menu of the focused item |

## Tabs and tasks

| Keys | Action |
|---|---|
| ⌘T | New task |
| ⇧⌘T | Plan with orchestrator: open a **Plan** tab with the plan editor. It starts no agent. |

Close a task with **File › Close Task** or the close button of its tab.

## Terminals

| Keys | Action |
|---|---|
| ⌥⌘T | New terminal |
| ⌘1 to ⌘9 | Focus the agent with that number |
| Tab, ⇧Tab | Go to the program in the focused terminal, for example for shell completion |
| ⌃Tab, ⌃⇧Tab | Move focus out of the terminal to the next or previous item |
| ↑, ↓ | Make your terminal's tile shorter or taller, while its resize handle has focus |

Tab does not leave a focused terminal. Use ⌃Tab.

## Swarm view

With a card focused in the [Swarm view](/swarm/docs/swarm-view/):

| Keys | Action |
|---|---|
| ←, → | Previous or next card |
| ↑, ↓ | Card above or below |
| ↩ | Focus the agent's tile |

## Review

Single keys work while the diff has focus and no text field does. See [Review](/swarm/docs/review/).

| Keys | Action |
|---|---|
| J | Next file |
| K | Previous file |
| V | Mark the file as viewed |
| C | Comment on the line |
| ↑, ↓ | Previous or next line in the diff |
| ⌥←, ⌥→ | Put the cursor on the old or new side of a split diff |
| ⌘↩ | Post the comment or reply |
| Esc | Cancel the comment or reply |

In the file tree:

| Keys | Action |
|---|---|
| ↑, ↓ | Previous or next row |
| Home, End | First or last row |
| ←, → | Close or open a folder |
| ↩, Space | Open the row |

## Palette, menus and dialogs

| Keys | Action |
|---|---|
| Tab, ⇧Tab | Next or previous item |
| ↑, ↓ | Move through the palette or a menu |
| ↩ | Choose the highlighted item |
| Space | Choose in a list menu |
| Home, End | First or last item in a list menu |
| Esc | Close the palette, a menu, a dialog, a notification toast or the menu bar popover |

## Text fields

| Keys | Action |
|---|---|
| ⌘A | Select all |
| ⌘Z, ⇧⌘Z | Undo or redo |
| ⌘X, ⌘C, ⌘V | Cut, copy or paste |
| ⌥←, ⌥→ | Move by word |
| ⌘←, ⌘→ | Move to the start or end of the line |
| ↩ | Submit a one-line field |
| ⌘↩ | Submit a multi-line field |
| ⇧↩ | New line in a multi-line field |

## Settings window

| Keys | Action |
|---|---|
| ⌘W | Close Settings |
| ↑, ↓ | Previous or next page in the list |

## Menu bar

The menus show the shortcut next to each item.

| Menu | Items with a shortcut |
|---|---|
| **Swarm** | **Settings…** ⌘, · **Hide Swarm** ⌘H · **Hide Others** ⌥⌘H · **Quit Swarm** ⌘Q |
| **File** | **New Task** ⌘T · **New Terminal** ⌥⌘T |
| **Edit** | **Undo** ⌘Z · **Redo** ⇧⌘Z · **Cut** ⌘X · **Copy** ⌘C · **Paste** ⌘V · **Select All** ⌘A |
| **View** | **Review** ⇧⌘R · **Toggle Sidebar** ⌘B · **Command Palette** ⌘K · **Enter Full Screen** ⌃⌘F |
| **Window** | **Minimize** ⌘M |

These items have no shortcut: **About Swarm**, **Show All**, **Add Project…**, **Close Task**, **Terminals**, **Swarm**, **Files**, **Changes**, **Zoom**, **Bring All to Front** and **Swarm Help**. Open **Swarm Help** to reach this site. **Terminals**, **Swarm** and **Review** also open from the view switcher in the window.
